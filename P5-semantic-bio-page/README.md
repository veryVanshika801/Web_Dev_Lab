# P5 - Semantic Bio Page

## Aim
Create a simple biography webpage using semantic HTML elements.

## Code: index.html
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Bio</title>
</head>
<body>
    <header>
        <h1>My Biography</h1>
        <nav>
            <a href="#about">About</a>
            <a href="#education">Education</a>
            <a href="#hobbies">Hobbies</a>
        </nav>
    </header>

    <main>
        <section id="about">
            <h2>About Me</h2>
            <p>Hello! I am a student interested in technology and learning new skills.</p>
        </section>

        <section id="education">
            <h2>Education</h2>
            <p>I am pursuing my undergraduate degree.</p>
        </section>

        <section id="hobbies">
            <h2>My Hobbies</h2>
            <p>I enjoy reading, exploring technology and working on small projects.</p>
        </section>
    </main>

    <footer>
        <p>© 2026 My Bio Page</p>
    </footer>
</body>
</html>
```

## Explanation
- `header` contains the page heading and navigation.
- `nav` contains links to sections of the page.
- `main` contains the main content.
- `section` groups related information.
- `footer` contains closing information.

## Steps
1. Create a folder named `P5-semantic-bio-page`.
2. Create a file named `index.html`.
3. Write the code and save it.
4. Open the file in a browser and click the navigation links.

## Result
A biography webpage was created using semantic HTML elements.
